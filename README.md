# Sparkling Saturdays

A lightweight launch website for a weekend cleaning business covering home, small-business and car cleaning.

## Launch checklist

1. Replace `hello@sparklingsaturdays.co.uk` in `script.js` with the real booking email.
2. Update service areas or pricing in `index.html` if needed.
3. Open `index.html` locally to preview.
4. Deploy the folder to Vercel, Netlify, GitHub Pages, or any static host.

## Booking form

The current starter form uses `mailto:` so it works without any backend account.

For a better production setup later, swap it for one of:
- Formspree
- Netlify Forms
- Tally / Typeform
- Calendly (for fixed slots)
- Supabase / custom booking backend

## Suggested next upgrade

Once demand is proven, add:
- fixed Saturday slot availability
- deposit payments
- WhatsApp confirmations
- postcode/service-area validation
- Google Reviews section
